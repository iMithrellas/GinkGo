# Documentation

[Install and start GinkGo](../README.md#install-and-start), then choose a guide:

- [Notes](usage.md): editing, search, export/import, original input, and editor setup.
- [Configuration](config.md): paths, namespaces, environment, and daemon troubleshooting.
- [Sync](sync.md): remote and server setup, encryption keys, and compatibility.
- [AI notes](ai.md): providers, generation, expansion, and fallback behavior.
- [Voice](voice.md): file transcription, dictation, live captions, and wake-selected notes.

## Reference

[CLI commands](markdown/ginkgo-cli.md) and [man pages](man/) are generated from the
command definitions. Run `ginkgo-cli COMMAND --help` for your installed version.

[Contributing](../CONTRIBUTING.md) covers builds, tests, and documentation updates.
